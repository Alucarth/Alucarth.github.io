# Alucarth.github.io

Portfolio construido con Vue 3 y Vite.

## Requisitos

- Node.js `^20.19.0` o `>=22.12.0`
- npm

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

Las imágenes del proyecto se incluyen desde `img/` durante la compilación con
nombres versionados en `dist/`.
